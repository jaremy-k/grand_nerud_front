# Визуальная проверка CRM

Запуск отдельного стенда:

```bash
npm run dev -- --config tests/visual/vite.config.ts
```

Страница: `http://127.0.0.1:3002/tests/visual/workspace.html`.
Для обычного сотрудника добавить `?role=employee`.

Карточки можно открыть напрямую через параметр `path`, например:

- `/tests/visual/workspace.html?path=%2Fdeals%2Fdeal`;
- `/tests/visual/workspace.html?path=%2Fdeals%2Fdeal%2Fedit`;
- `/tests/visual/workspace.html?path=%2Fcompanies%2Fquarry`.

В стенде есть связанные компании, сделка, адреса, прайс-лист, лиды и задачи. Ответ калькулятора фиксированный, только для визуальной проверки: это не проверка формул. Сохранение тестовой сделки меняет данные только в памяти вкладки.

Используются настоящие компоненты, маршруты, sidebar и CSS приложения, но отдельная подмена API в конфигурации Vite. Запросы не уходят в рабочий backend, токены не читаются. Неописанные операции возвращают ошибку. Изменения тестовых данных хранятся только в памяти вкладки.

Эта страница не подключена к основному приложению и не входит в production-сборку. Она проверяет интерфейс, а не серверные права и бизнес-логику реального API.
